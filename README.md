# 🏡 Grama Vasathi - Rural Hospitality Android App

Grama Vasathi is an Android-based hospitality application developed using Kotlin.

## Features

- Login and Registration
- Accommodation Booking
- User Profile
- Chatbot Support
- Feedback System
- Clean Android UI

## Tech Stack

- Kotlin
- Android Studio
- Gradle Kotlin DSL
